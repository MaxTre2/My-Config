# MaxTre - VPN

## 🚀 Автоматическое обновление конфигураций VPN

Этот репозиторий автоматически собирает и обновляет рабочие VPN конфигурации для обхода блокировок.

### 📥 Ссылка для подписки

Скопируйте эту ссылку и вставьте в ваш VPN клиент (Happ, v2rayNG, NekoBox и др.):
https://raw.githubusercontent.com/MaxTre2/My-Config/refs/heads/main/ByPassVpnLera.txt

### ⚙️ Как добавить в Happ

1. Откройте приложение **Happ**
2. Нажмите на кнопку **"+"** в правом верхнем углу
3. Выберите **"Добавить подписку"**
4. В поле **"Заголовок"** введите: `MaxTre - VPN`
5. В поле **"URL"** вставьте ссылку выше
6. Нажмите **"Добавить"**
